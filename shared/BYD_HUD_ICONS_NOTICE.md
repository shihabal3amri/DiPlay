# BYD HUD maneuver icons

`src/main/assets/byd-hud-icons/0x<code>.png` (48 files, 38x41 px) are taken from BYDMate
(https://github.com/AndyShaman/BYDMate, `app/src/main/assets/navi/`). The file name is the Gaode maneuver code
(see `hud/BydManeuverCodes.kt`). The BYDMate project itself describes them as donor assets.
