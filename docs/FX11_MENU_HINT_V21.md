# MENU 仪表切换提示（v21 测试版）

三套仪表（Midnight／全景／经典复刻）增加同一款青色提示：上一曲图标、`仪表切换`、下一曲图标。它位于内容区域底部，退出模式后完全消失，不占用固定空白栏，也不移动表盘、灯光和车况。

## 使用

1. 保持博越 L 方控和自定义仪表开启，按 MENU 进入原车仪表菜单。
2. 收到原厂菜单反馈、确认上下曲监听就绪后，出现 `仪表切换`；短按上一曲／下一曲切换内容。
3. 再按 MENU 退出，收到退出反馈后提示消失，上下曲恢复原有媒体按键逻辑。
4. Midnight／经典复刻切换音乐、导航、胎压；全景保留地图，切换音乐与胎压卡片。

提示与翻页操作共用同一个状态判断，刷新间隔最多 250 ms。初次等待状态、电话或未知状态、输入服务断开、注册失败、方控关闭、仪表关闭、按键学习期间均隐藏；移除仪表视图时清除提示。没有新增开关，也不根据 MENU 按压次数猜测开关状态。

MODE 的原厂／自定义仪表切换保留。普通 CarPlay、导航声音修复、界面放大、FX11 数据、Geely 图标、关闭应用更新提示、v19 认证恢复及 v20 MENU 监听均保留。诊断新增 `menuPagingActive`，可以与 DIM 回调和 track 路由记录对照。

## 验证与限制

- 本地集成测试覆盖三套实际仪表视图：初始隐藏、进入显示、翻页保持显示、退出隐藏、视图移除清除，以及输入断开／设置关闭／学习状态。
- 原生绘制截图覆盖三套仪表的所有页面、1920×532 与 960×266、大字体及阿拉伯语；验证提示外像素不受影响，退出后提示完全清除。
- 执行仓库要求的单元测试、三个应用的 lint／debug 构建及完整认证资源构建；测试结果和安装包校验记录随包提供。
- 原厂 DIM `onTabChanged` 与 MENU 的对应、MENU 打开时是否转发上下曲仍需实车验证；本版没有连接车辆验证。缺少真实回调时提示保持隐藏，不假称已经进入模式。原有 v20 接口证据及限制见 `FX11_MENU_WHEEL_V20.md`。

## 安装

包名 `com.shihab.diplay.hudtest`，versionCode 52，版本 `0.2.20-hud-test-v21`。与 v20 使用同一签名，可直接覆盖安装并保留设置，无需卸载。发布校验将认证文件及全部 assets／native libraries 与 v20 逐项比对。

停车后可先验证：MENU → 提示出现 → 上下曲翻页 → MENU → 提示消失 → 上下曲切歌。若提示没有出现，请导出诊断，查看 `DIM menu` 和 `menuPagingActive`，无需重新学习 MENU。
