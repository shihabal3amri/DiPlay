# v41 经典表盘参考图对齐

依据用户提供的仪表照片调整经典仪表两个圆盘的视觉样式：
- 更暗的墨绿色刻度盘、深黑中心、细银灰外缘。
- 永久银灰渐变下环带，连续衔接随车速／转速变化的银色刻度扇区。
- 减细青绿色内圈和主／副刻度，略收小数字标签与中央速度字号。
- 银色区域深色刻度、暗色区域浅色刻度；转速红线和正确的 0–8 ×1000 标尺保持不变。

仅对齐圆盘样式。保持 1920×532 现有布局、地图宽度、右侧音乐封面、下方档位与剩余续航、顶部灯光栏左右内边距和单侧圆角。速度继续用 km/h，温度继续用 °C，缺失读数继续显示未知。参考图的 mph、英里、Sport 字样和挡位中心布局不覆盖已经确认的产品功能。

三套仪表、普通 CarPlay、现有认证与签名保持兼容。构建验证见 verification.json；预览包含测试数据与示意地图，不代表真实车辆采集结果。
