# v43 经典仪表固定量程渐变与自动日夜配色

## 本次实现
- 1920×532：灯光／辅助驾驶栏从 y=0 开始，底部信息栏延伸至 y=532；仅朝向地图的内侧角为圆角。保留左右转向灯两侧的 16px 内边距，音乐、导航、胎压共用同一布局。
- 白天速度刻度固定按 0–240 km/h 从浅绿渐变至深绿，显示到当前读数；转速按 0–8000 rpm 使用同样逻辑。读数变化不会拉伸渐变，未编号的底部桥接段保持浅色。
- 渐变区刻度数字按所在位置选择深色或白色，转速底部实际数值加粗并使用深色，保证可读。
- 「经典仪表配色」新增「自动（6–18点白天）」：按车机本地时间，06:00（含）至18:00（不含）为白天，其余为夜间。保留手动白天／夜间选择与原有保存值。
- 运行中每次现有 UI 更新都会重新判定配色，无需重启或重连 CarPlay，不改变地图 TextureView、页面、窗口大小或 iPhone 地图配色。

## 使用
设置 → 高级 → 博越 L 仪表 → 选择经典仪表 → 经典仪表配色 → 自动（6–18点白天）。
默认仍保留之前保存的配色，升级不会强制切换已有设置。

## AutoHold 的实证边界
当前 FX11 绑定没有已确认的 AUTO_HOLD_ACTIVE 反馈。示例已有的电子驻车／手刹反馈不能当作 AutoHold，因此未增加猜测属性或根据档位、车速推断。未知和未保持时为灰色，确认保持后为绿色；手刹确认拉起为红色。测试图中的绿色 AutoHold 来自测试夹具，不证明实车已能读取；该读取问题需后续连接车机核验。

## 保留与验证
保留三套自定义仪表、原厂叠加、普通 CarPlay、方向盘配置和既有认证。实际地图为手机传入视频，预览里的道路和车况是测试数据，不会作为实车数据打包。

测试覆盖自动时间边界与本地时区、手动设置不变、设置持久化、固定量程渐变单调性和底桥颜色、上下贴边和内侧圆角、AutoHold 显示状态、其他仪表配色保持、地图像素及视频对象保持。完整 CI、lint、APK 构建和签名／认证校验结果见输出目录 verification.json。
