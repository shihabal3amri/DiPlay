# v32 仪表地图车标位置（待实车验证）

## 证据与边界

用户照片中，经典仪表导航车标/道路视角偏右，但灯光栏、导航卡片、圆盘没有同样偏移。
本地检查确认 `NativeDashboardView.fittedMap()` 按窗口中心等比例布局，经典样式执行居中 cover；
v31 给 iPhone 的经典地图为 1388×532，safeArea 左右均为 282。未找到固定向右平移代码。
因此尚不能断言根因是 Android 布局，也不能声称已确认高德如何使用 safeArea。
照片中的路线总览与跟随导航还可能采用不同相机布局。

## 本次候选修复

- 将本地仪表的 stream 111 配置集中到 NativeDashboardMapConfig，尺寸、物理宽度设置和 URL 保持原有值。
- 原来的大块无遮挡区域改为更窄的横向车标安全带：宽度取无遮挡区的 40% 与视频宽度的 20% 中较小者，垂直边距不变。
- 经典仪表默认焦点 x=694（视频内），映射到 1920×532 仪表 x=960；安全带 x=555..833。
- 全景默认焦点 x=556（视频内），对应仪表 x=988，位于左侧车速和右侧音乐卡片之间。
- Midnight/OEM 以各自地图窗口中心为基准。道路允许绘制到安全带之外，视频窗口不移动、不放大、不新增裁剪。
- “高级 → 博越 L 仪表 → 仪表地图车标位置”：默认居中，可左右微调 5/10/15 个百分点（相对于无遮挡区域宽度）。各样式分别保存；重连 CarPlay 生效，不主动中断连接。
- 该设置只请求 iPhone 地图的安全区域；不检测或移动像素中的真实车标，不能强制第三方地图遵守，也不会把路线总览伪装成跟随模式。
- 连接日志记录样式、视频尺寸、物理宽度、位置百分比、安全区；窗口诊断仍记录 TextureView 实际边界。

## 保留

普通 CarPlay、三套本地仪表、实验性原厂叠加、v31 水温备用读取、封面保留、歌曲名与歌手名滚动和独立地图大小设置。
主屏配置、解码路径、实际车辆信号读取、灯光/档位和按键处理均未改动。
认证材料和 native libraries 在打包时逐项对照 v31；凭据不写入本报告。

## 验证

新增测试检查实际 /info 字典：车标区域随设置单调移动、始终位于无遮挡区内、地图视频窗口/主屏声明不变；
覆盖四种样式、四种地图尺寸、全部微调档位，以及各样式偏好保存与所有页面的主机配置。
现有仪表布局和普通 CarPlay 测试继续运行；设置页有窄屏、大字体、完整屏和阿拉伯语截图。
最终构建测试结果见输出目录 verification.json / build.log。

当前 ADB 无设备。不能确认该 iPhone/高德版本是否服从安全带，亦未验证实车居中效果。
安装后请先重连 CarPlay，使用正在导航的跟随视角观察；如仍偏右，尝试“向左 10%”并重连。
若完全无变化，需要新诊断和实际副屏帧区分应用忽略安全区、旧会话参数缓存与路线总览视角，不应继续盲目改变窗口坐标。
