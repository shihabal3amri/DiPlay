# FX11 分支合并记录（2026-10-24）

本分支专为 FX11 车机使用，维护分支为 `fx11`，远程仓库为 `zmisgod/DiPlay`。

## 合并来源

- FX11 定制基线：`6c09a1cd`（包含此前 v46 的修改）。
- 上游 DiPlay：`4487c689bfdd3baab12de67a993a671b67939eb7`，0.2.21 系列。
- 保留双方提交历史，以合并提交记录集成；不覆盖远程 `main`。
- 测试版标识：`0.2.21-hud-test-v47`，versionCode 78，包名仍为 `com.shihab.diplay.hudtest`。

## FX11 保留与集成

- 保留 Midnight、Panorama、Classic 三套仪表和现有原厂叠加模式。
- 保留 FX11 的车速、档位、车灯、温度、续航、胎压等数据接入，以及 QNX telltale 32 的 AutoHold 实际保持状态读取。未确认的辅助驾驶状态继续按未知处理。
- 保留方向盘短按／长按配置、原厂与自定义仪表切换、内容翻页、Geely 图标及禁用更新提示。
- 保留地图尺寸／位置、经典仪表自动日夜配色、白天黑底、重绘优化和卡顿诊断。
- 保留普通 CarPlay、原有 Ultra 实验代码、FX11 数据协议能力，以及可选择的麦克风输入源和设备。
- 集成上游无线／USB 恢复、音频模式释放、导航 PCM 音量处理和麦克风静音诊断。
- 集成上游封面保留策略：等待新封面期间保留已有封面，断开会话后清空；迟到的旧会话结果不能覆盖新会话。FX11 仍接收歌曲进度和播放状态，原厂 DIM 信息输出保留。
- 上游停止地图后的仪表释放逻辑不接管 FX11 本地仪表，车辆读数仍可在没有 CarPlay 地图时显示。
- 同时保留“最大／超大”CarPlay 字体图标选项和上游新增的自定义物理尺寸设置。
- 为上游新增的意大利语补齐 FX11 设置文案；`fx11` 分支推送也运行 Android CI。

## 构建与验证

按根目录 `AGENTS.md` 执行 shared、common、home 单元测试，mobile、home、maphost Lint 与 Debug 构建。
新增／更新回归覆盖 FX11 仪表不随地图结束被释放、封面与歌曲状态、五档及自定义 CarPlay 尺寸和按请求发送位置数据。

认证材料继续通过仓库外的 `DIPLAY_AUTH_ASSETS_DIR` 提供。GitHub 源码不包含私钥、证书或本地 APK；普通 CI 构建默认没有运行时认证材料。详见 [构建说明](BUILD.md)。

本次完成本机构建与自动化验证，未进行新的车机实测。原厂叠加与 Ultra 的既有限制没有因代码合并而变成已验证支持。
