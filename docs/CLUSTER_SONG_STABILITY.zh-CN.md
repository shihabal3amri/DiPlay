# 原车歌曲信息补充

我在 2023 唐 DM-i 冠军版、21 控制器上遇到原车歌曲栏写入不稳定，以及歌名和歌手挤在一起的问题。本次在主线已有歌曲、播放状态、切歌显示 5 秒及滚轮提示功能上补充适配。

来源字段从车机 SDK 的 `INSTRUMENT_MUSIC_SOURCE_SET` 解析，只接受已核对的 `0x43E00030` / `0x38F00030`，设备仍为 1007。字段缺失或未知时不猜写来源地址，播放状态和文字仍分别尝试。每个字段独立确认，来源失败 30 秒后再试，状态失败 5 秒后再试，避免每句歌词重复写控制字段。保留主线已观察到的厂商返回值兼容；文字成功不代表来源成功，日志单独给出来源确认情况。

ADB 使用已授权的专属交互 shell，常驻 `app_process` 初始化一次 SDK，通过随机令牌及有界协议传输。每 5 秒续租，15 秒未续租退出；结束或关闭歌曲时关闭 worker，不新增网络服务。worker 只接受来源、播放状态和有长度限制的歌曲文字操作，保留滚轮提示使用的来源图标。

新增“原车歌曲栏显示歌手”，默认开启，立即生效，仅改变原车歌曲栏，Android 媒体元数据保持完整。原有歌曲总开关默认关闭，不改变公开包名及品牌。测试覆盖 SDK 字段、失败隔离、控制字段退避和协议约束，并生成大字体中文窄屏、全宽合成截图；多语言及 RTL 检查仅用于自动测试。没有安装到车机，worker 在不同 ROM 的权限、续租表现及实际仪表显示需要实车验证。
