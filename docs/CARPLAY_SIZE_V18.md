# CarPlay 图标尺寸扩展 v18

## 使用方法

设置 → 显示 → CarPlay 尺寸，先试“超大”，仍偏小再试“最大”。
应用时按界面提示重新连接 CarPlay；连接前设置则在下次连接时使用。
无需更改音乐或导航声音通道。

“分辨率”的 160% 上限控制视频像素数，不是图标放大倍率。
此版本扩展的是现有 CarPlay 尺寸选项，通过向 iPhone 报告较小的屏幕物理尺寸请求更大的图标和文字。
实际排版由 iOS 决定，可能减少一屏内容；这些档位不代表保证的百分比放大。
部分 iOS 版本可能忽略尺寸变化，需要在真实 iPhone 上确认。

| 选项 | 报告的参考物理长度 |
| --- | --- |
| 最大（新增） | 150 mm |
| 超大（新增） | 200 mm |
| 大 | 250 mm |
| 中（默认） | 300 mm |
| 小 | 350 mm |

沿用原有物理尺寸设置和宽／高参考方向；默认按宽度计算。
高级设置如果选了高度，保留该选择。窗口缩小时仍按现有最大窗口比例计算。
之前保存的数值不会因选项增加被覆盖，默认仍是“中”。

## 范围与验证

- 保持视频分辨率范围 30–160%、帧率、画布、触控映射和地图副屏配置不变。
- 八种语言补齐新选项，并提示应用会重新连接。
- 设置测试覆盖新增档位保存和重开、旧档位索引、取消不保存、分辨率不变。
- Host 测试从保存的尺寸加载连接配置，验证 150/200 mm 实际进入配置，画布及其他显示参数不变。
- 沿用 v17 高德导航 Opus 软件解码回退；三套仪表、FX11、普通 CarPlay、Geely 图标与禁用更新提示功能均保留。
- 完整测试、lint、APK 构建和签名／认证资源校验结果见交付目录 verification.json。

本次未完成真实 iPhone 图标大小或车机导航声音的验证。无需卸载旧测试版，使用同签名 APK 覆盖安装即可保留设置。
