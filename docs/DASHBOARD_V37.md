# v37：FX11 MODE 默认键码与已有动作迁移

2026-10-23 实车证据：型号 `FX11_LOW`，OneOS 短按 MODE 上报 `200400`。
升级 v36 后当前安装的 `native_dashboard.xml` 没有 `mode_key`；界面因此使用 SDK
默认 `200110`，用户保存的短按 `CYCLE_DASHBOARD` 和长按 `TOGGLE_DASHBOARD`
均绑定到该无实际事件的代码。不能假设早期诊断保存过的校准在当前安装仍存在。

修复：
- 仅在明确选择博越 L 且 `Build.MODEL == FX11_LOW` 时，未校准 MODE 默认使用 200400。
- 其他型号和显式校准值保持原样。
- 在启动及选择车型时，将旧 200110 的短按/长按动作分别迁移到 200400，一次执行，
  不覆盖已有 200400 动作，不修改其他按键和样式。若 200400 已作为学习翻页键则不迁移动作。
- 不拦截原车按键；不修改 MENU、音量、ADAS 或 CarPlay 的处理。

回归：覆盖 v36 迁移标记已存在时的升级、两个独立动作的保留、幂等性、目标动作优先、
显式校准保留以及其他型号默认值。完整构建报告见 outputs/diplay-dashboard-v37。
实车按压后的显示效果仍需用户观察，不能仅由安装成功推断。
