# 氛围灯颜色与短促节拍

我在2023款唐DM-i冠军版、21控制器上使用音乐氛围灯时，发现单看一排色块不容易分清相近颜色。这次给31个原车预览色补上名称，白色、冷白分别标出。名称只是帮助选择，不代表实测灯光色值；保留原来的颜色编号及保存方式。

保留上游的音乐律动、封面取色、原车律动、暂停和空闲恢复策略，只在灯光提交节流处补上短促亮度峰值：两次允许写入之间的短拍会带到下一次提交，提交后仍能回到暗部。暂停、静态模式、关闭和恢复时清除待提交峰值，不提高硬件写入频率。

颜色卡片随窄屏换行并支持从右到左布局；每种语言都使用对应颜色名称。公开截图只展示中文。自动化覆盖颜色数量、白色区分、选择行为及短拍保留/暂停清除。合成截图用于检查布局，不代表实车视觉效果；本次未安装到车机验证。

本次主线移植已通过仓库要求的完整检查：3028项单元测试，0失败、1项既有跳过；三个应用的静态检查和调试构建通过，公共树及差异检查通过。
