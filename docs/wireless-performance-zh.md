# 无线性能保护

在2023款唐DM-i冠军版、21控制器上，我希望连接期间尽量避免 Wi-Fi 省电带来的短时延迟。这次增加可选的会话性能请求，不修改热点、密码、扫描、选网或配对逻辑。

在“高级”中开启“无线性能保护（实验性）”，下次连接生效。默认关闭，已有用户行为不变。只对无线 CarPlay 有效：会话激活时请求 HIGH_PERF，Android 10 起同时请求 LOW_LATENCY；会话结束或控制器关闭时释放。锁不可用或权限被车机拒绝时继续原连接流程。

这是 Android 性能提示，不能保证车机固件采纳，也不承诺降低具体毫秒数。自动化测试覆盖 API 分支、重复获取和释放、单模式失败及释放异常。未在该车机进行本次修改的实车验证。

本次主线移植已通过仓库要求的完整检查：3029项单元测试，0失败、1项既有跳过；三个应用的静态检查和调试构建通过，公共树及差异检查通过。
