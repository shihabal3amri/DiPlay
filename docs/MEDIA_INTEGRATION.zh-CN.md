# 原车媒体信息与音乐联动

这些功能的自用实现已在我自己的2023唐DM-i冠军版、21控制器上实测。这次按原车媒体使用场景，将歌曲信息、静音播放联动和音乐氛围灯整理为同一项主线移植。

## 原车歌曲信息

来源字段从车机 SDK 的 `INSTRUMENT_MUSIC_SOURCE_SET` 解析，只接受已核对的 `0x43E00030` / `0x38F00030`，设备仍为1007。字段缺失或未知时不猜写地址，播放状态和文字分别尝试。来源与状态独立确认，分别在失败30秒和5秒后重试，避免每句歌词重复写控制字段；保留上游已观察到的厂商返回值兼容。

ADB 使用已授权的专属交互 shell，常驻 app_process 初始化一次 SDK，不新增网络服务。关闭歌曲总开关或 CarPlay 会话结束时，写入队列发送 stop，尝试清空歌曲卡后关闭 shell/ADB 连接，worker 返回后退出。仅关闭 DiPlay 页面不会结束仍运行的会话。DiPlay 进程被结束或 ADB 断开时，worker 读到 EOF/错误便退出；若连接未及时反映断开，客户端不再每 5 秒续租，worker 在超过 15 秒后由下一次每秒巡检退出。厂商写入阻塞时也由该看门狗退出。

令牌由客户端在每次启动 worker 时使用 SecureRandom 生成 16 字节随机数，转为 32 位十六进制，经已授权 ADB shell 的 app_process 启动参数传入；每条标准输入请求带同一令牌。令牌仅保存在客户端和 worker 内存中，不写入设置、文件或应用日志；它也出现在启动命令参数中，并不是对同权限 shell 隐藏的凭据。协议只接受受限的歌曲字段写入，不提供任意 shell 执行。

“原车歌曲栏显示歌手”默认开启，立即生效，只影响OEM歌曲栏。Android媒体元数据仍保留歌手。歌曲总开关仍默认关闭；保留歌曲变化5秒显示、滚轮提示和会话退出流程。

## 车机静音联动

高级媒体设置新增实验性开关，默认关闭。观察Android音乐声道的真实静音状态，广播触发采样，每500毫秒补采；音量零不等于静音。静音发送明确的PAUSE，解除静音发送明确的PLAY，包括原来已经暂停的媒体。

Android通话、CarPlay通话和Siri优先，保护整个语音流生命周期，包含声音间隙。语音期间的边沿延后处理；手动媒体操作、停用、断线、未知静音值或会话更换会清除待发操作。发送前及执行时再次核对主屏会话令牌，过期指令不会跨重连发送。

## 音乐氛围灯

为31个原车预览色补充名称，区分白色和冷白，编号和保存方式不变。颜色名只帮助选择，不代表实测灯光色值。所有现有语言均提供颜色名称和相同的文案占位参数，包括意大利语。

短促亮度峰值保留到下一次允许的硬件提交，不提高原有写入频率；仅跟随播放模式启用，原车律动模式不叠加。暂停、静态模式、关闭、恢复和会话重置时清除待提交峰值。保留上游封面取色、空闲和恢复策略。
