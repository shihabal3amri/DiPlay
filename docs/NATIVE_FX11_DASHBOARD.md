# FX11 本地仪表 v16：午夜、全景与经典复刻

经典复刻最新布局与水温/驻车状态的证据边界见 [REPLICA_DASHBOARD_V16.md](REPLICA_DASHBOARD_V16.md)。下方 v11–v13 章节为历史记录。

三套界面均由 DiPlay HUD Test 在 Android 端绘制，适配 1920×532。它们使用普通 CarPlay 的副屏地图，不需要 Ultra；没有连接 iPhone 时仍读取 FX11 车况。没有有效来源的数值显示“—”，未知灯光与辅助驾驶图标保持灰色；AUTO 档位未知时隐藏 A 图标。

## 安装与选择

1. 覆盖安装 v16 HUD Test，不需要卸载旧 HUD Test；同包名、同签名，保留已有设置和认证资源。
2. 设置 → 车辆 → 车型选择 **博越 L**，启用方向盘控制。
3. 设置 → 高级 → 博越 L 仪表显示（实验性）→ 本地仪表样式，选择 **午夜 · 双圆表盘**、**全景 · 宽幅地图**或 **经典复刻 · 双表大地图**。
4. “预览实时仪表”在中控展示相同渲染器；它不注入示例数据。仪表实际输出仅使用已确认规格的 Display 4。
5. 按 **MODE** 切换原车三屏动态开关，在原厂仪表与本地仪表之间切换。启用本地画面前检查窗口已绘制；读回 OEM 开关确认结果。仅选择样式不会自动写原车开关。
6. “仪表内容按键”进入识别，按原车用于切换音乐/导航的那个键，确认后绑定。尚无实体按键码证据，默认不绑定。它切换本地音乐、导航或胎压；MODE 不再切页。
7. 首次启用、关闭或切换样式后，地图尺寸在下一次 CarPlay 连接时生效。界面会显示重新连接提示，不主动断开手机；本地页面切换即时生效。
8. 关闭仪表时选择样式“关闭”或常驻通知的关闭操作。只有确认原车三屏开关恢复为 0 后才停止窗口。失败会保留当前样式并记录诊断，避免单纯销毁投影窗口。

原车按键仍有原厂行为：DiPlay 使用观察订阅，不拦截、不取消原厂按键动作。学习期间不会由 DiPlay 执行媒体、投影或切页动作；学习仅限已知媒体/菜单键，排除辅助驾驶方向键、滚轮、音量及 MODE。识别 45 秒后结束，可清除绑定。

## 三套布局

| 样式 | 内容切换 | 地图流与布局 |
| --- | --- | --- |
| 午夜 | 音乐 → 导航 → 胎压 | 导航页右侧 1408×400 地图；转速改成车速下方文字。音乐/胎压页保留右转速表。 |
| 全景 | 地图 + 音乐 ↔ 地图 + 胎压 | 1488×472 地图与 360×142 卡片；切卡片不销毁地图，不重连。 |
| 经典复刻 | 音乐 → 导航 → 胎压 | 银灰扇形与青绿内圈双表；直径508；1388×532 地图位于 (266,0)–(1654,532)，延伸到圆盘中心，圆盘完整不透底。 |

三套样式独立记忆页面，经典复刻默认音乐。没有活动导航时，**导航文字提示卡和全景到达时间卡完全隐藏**，不显示空白卡片或占位箭头。存在副屏地图流时仍可展示地图；未收到地图新帧时显示暂无地图数据。导航退出、到达终点和 CarPlay 断开会清空导航状态。

音乐使用真实歌名、艺人、专辑、封面及播放进度，不显示播放时间数字。胎压使用四轮 bar 读数，单轮缺失单独显示“—”。图中的测试数据仅存在于单元测试 fixture，不进入运行时。

经典复刻左表显示车速 km/h 和水温；右表显示档位与发动机转速，刻度 0–8，单位 ×1000 rpm。三页共用顶栏，AUTO 合并进近光图标，左右转向位于整排两端，辅助驾驶用颜色表达状态，设定速度带 km/h。跟车距离条由上至下从长到短。底部居中显示时间、外温及剩余 km，不再在圆盘内显示油量百分比。音乐背景跟随真实封面颜色，AutoHold/手刹/陡坡缓降仅在已确认状态时出现。

v32 将地图的车标安全区收窄到无遮挡区域中央，并允许按样式独立左右微调。经典复刻默认 safeArea 为上 160、下 68、左右 555，视频尺寸仍为 1388×532；全景避开右侧卡片，默认焦点位于视频 x=556。地图仍允许绘制到安全区外，窗口、圆盘和现有等比例缩放保持不变。重连生效；iPhone/高德是否响应需要实测。详见 [v32 居中调整](DASHBOARD_MAP_CENTERING_V32.md)。

## 车况与本次修正

逐项来源、换算和证据边界见 [FX11_DATA_AVAILABILITY.md](FX11_DATA_AVAILABILITY.md)。

- 油量、原厂续航、四轮胎压和厂商温度共七个实车验证属性，在配置目录缺失时仍直接只读查询；有配置但不可读或区域不匹配时仍拒绝。
- 剩余续航只显示原厂 `PA_TS_DTEIndicated`，温度只显示厂商 `559970552`。本车标准值已与原厂对照不符，不再作为显示后备；厂商值失败或过期则未知。合法 0 不被替换，不按油量估算续航。
- 胎压按本车实测 PA data ÷ 10 转为 bar，raw 23 对应原厂 2.3 bar。
- 原生扩展灯光/ADAS 的厂商 INT32 属性兼容单个 float payload，严格校验整数枚举。1.0 可以表达灯亮，1.5 不会被截断为灯亮。
- 多属性读取不再因为一整轮超过 3 秒就停采；仅在连续等待窗口没有进展时判断读取卡住。读取线程仍有固定上限。
- 常亮灯、油量等 ON_CHANGE 值的旧正时间戳可以成功续期；失败/不可用或超过 2.5 秒没有成功确认则失效。速度仍要求源事件在 2 秒内。
- 诊断逐项记录 config、返回码、状态、int/float 槽、PA 四字段、事件年龄、最后成功时间与拒绝原因，避免把“未知”描述成“关闭”。

2026-10-16 已通过 ADB 采样：厂商续航111 km、四轮PA data均23、温度23.3°C与用户原厂对照相符；油量PA data为17但尚缺原厂百分比对照。v9运行诊断确认缺配置过滤，胎压旧倍率也不正确。新包安装后的具体读数与验证范围见交付目录，不将静止采样推广为全部工况已验证。

当前仍未完成可靠显示的项目：

- **本车 ACC 设定速度**：标准 `0x11601013` 的 m/s 换算已实现，但旧 FX11 配置未证实有这个属性。厂商反馈 `557849502` 已记录 raw，单位/比例未知，不能当 km/h 或用当前车速代替。
- **实际车道居中**：lateral INDCR 和 timeout 只作诊断，状态枚举仍未知；不从 GPilot 选择、ACC 工作或车道线颜色推断居中激活。GPilot 的方向盘只有纵向与横向都已确认工作才亮绿，目前横向未知时保持灰色。
- **自动大灯**：v11 已停用不可靠的标准 HEADLIGHTS_SWITCH=256，改读 ECARX 原厂外灯选择器；本车尚未确认可用时保持未知并隐藏 A 图标，近光亮不表示自动模式。
- **前雾灯**：UI 已有图标，缺可靠反馈属性，保持未知。

辅助驾驶方向键和跟车滚轮继续由原车控制；本地仪表只显示回读。未新增触屏辅助驾驶控制。安全带与总里程仍保留底层读取，但按用户要求不在仪表显示。

## 原厂仪表切换

固定调用 ECARX `SETTING_FUNC_THREE_SCREEN_ANIMATION`（540148992），只允许 global zone 与 0/1 枚举。读取当前值后执行一次切换，有限次数读回确认；超时或失败不重试写入。关闭本地仪表固定恢复 0；已经是 0 则不写。

切回原厂时仍保留本地服务与按键订阅，保证离线时可以再按 MODE 切回。Display 4 消失时释放窗口，重现后重建。投影窗口未完成首帧时不能开启三屏，但始终允许明确恢复原厂。详见 [FX11_THREE_SCREEN_CONTROL.md](FX11_THREE_SCREEN_CONTROL.md)。

应用启动、页面切换与服务销毁均不会自动切换原车开关；强行结束进程不等于恢复原厂。正常退出请用关闭操作或 MODE 切回。Android 窗口创建成功、OEM 开关读回成功也不等于物理仪表已验证显示。

## 诊断与验证

设置 → 诊断 → 保存诊断报告，或博越 L 仪表显示内的诊断按钮，包含当前样式、页面按键、原车开关结果和逐项 FX11 数据。复测时将原厂显示的油量%、剩余 km、四轮 bar 与报告配对；灯光可记录开关变化前后数据。未知字段不会用示例值补齐。

普通 CarPlay、v8 连接修复/Ultra 有限重试、原厂 DIM 音乐导航、博越 L 方控、Geely 图标、禁用更新提示均保留。本地仪表开启时继续抑制 Ultra 协商和旧全屏地图窗口，避免争抢副屏；手机断开只清空音乐、导航和地图，车辆数据独立运行。

核心代码：`NativeDashboardView.kt`、`NativeDashboardRuntime.kt`、`NativeDashboardService.kt`、`Fx11VehicleSource.kt`、`Fx11ThreeScreenController.kt`、`GeelyWheelKeys.kt`。测试覆盖实际 Canvas 截图、三套无导航状态、按键学习/路由、原车开关验证与车辆读取。APK交付目录记录完整CI、签名核验及安装后的实车检查结果；未进行的行驶、地图或辅助驾驶状态验证应继续标为待验证。

## v11 灯光与 RESET 修复

- 左转向原始 RX/APA 反馈已随用户操作出现 0/1。把 RX 左右转向加入配置缺失时的精确只读名单，保留状态、区域、时间戳校验；右转向点亮尚待实车对照。
- v10 的标准自动大灯值始终为256，与用户实际档位不符，已废弃该来源。A 图标改读 ECARX 外灯档位；不支持、失败、过期时保持未知。原厂选择器仍需本车验证。
- RESET 通过仪表内容按键学习后保存真实键码；300050仅作候选，不猜测默认绑定。新增六类回调日志。MODE继续切换三屏动态。
- 保留三套仪表、普通CarPlay、原有油量/续航/胎压/温度修复；ACC设定速度与车道居中未确认状态仍未知。

### v11 无需切屏诊断

ADB 可只读执行 `dumpsys activity service com.shihab.diplay.hudtest/com.shilapi.xcertplay.NativeDashboardService`。
输出当前仪表、FX11属性与方控回调；不解析动作参数、不写车辆状态、不输出媒体内容。
页面键尚未绑定时只观察有限14个候选，仍不自动保存/翻页；绑定后恢复最小监听集合。


## V12: 本车 MODE 校准与未知 AUTO 图标 (2026-10-16)

- 本车单独短按 MODE，新增完整 `200400` down/up/short 回调；此前写死的 SDK MODE `200110` 不适配本车。拉取的 `com.geely.inputservice` 1.0.20260509G(5d) 上游数组含200400、不含200110。SDK对200400的名称仍为WECHAT，物理对应依据是本次隔离按压，不能推广为所有吉利车辆的固定映射。
- 新增安装级 `native_dashboard.mode_key`，未设置仍200110；本车部署保存已确认200400。注册、分流及诊断统一使用保存值，翻页键与MODE禁止冲突，未确认的RESET继续未绑定。旧冲突配置读作未绑定；学习忽略当前MODE，避免误存成翻页键。
- 三套样式中，AUTO状态未知时完全不绘制该灯图标与A字；已知开/关保持绿/暗灰。保留其它灯、三套仪表、普通CarPlay及V10油量/续航/胎压/温度读取。ACC设定速度及车道居中未确认项仍未知。
- RESET在前一轮14候选监听内，两次隔离短按未产生新回调；这只是该外发路径的阴性结果，不能证明车辆不发送RESET，也未据此猜码绑定。后续范围限定为本车InputService固定31唯一码的临时被动监听，以及HW_KEY_INPUT单属性订阅；均不拦截、不写车辆属性。
- 原始静态与运行时证据保存于 `outputs/diplay-native-dashboard-v11/device/inputservice-analysis/` 和 `runtime-reset-isolated.txt`。本节先记录代码与证据边界，实车安装/最终读回应以V12交付目录installation与device记录为准。


## v13：经典复刻满高布局

- 按确认的样式图放大双圆盘，保持正圆和 1920×532 设计空间。左右转向、全部车灯和辅助驾驶集中到中间顶部一排，不再占用圆盘上方和底部栏。
