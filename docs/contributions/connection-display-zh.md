# 连接与画面切换体验

这组把连接等待、分屏尺寸记忆和无线会话性能保护放在一起，处理从连接到画面切换的衔接。相关自用功能已在我自己的23款唐 DM-i 冠军版、21控制器上实测；这里沿用公共主线的连接和显示框架，不包含自用品牌、私有配置或车内截图。

- 主屏和仪表等待页最多运行五秒。首帧通知同时校验会话和输出版本，旧解码器、镜像或排队回调不能解除新的等待。
- 每个方向最多记住三档稳定分屏比例，下次全屏连接时声明。发送区域切换后，只有有效的本地快照才启用最长1200毫秒的衔接；显示期间释放旧触点，恢复时要求新的按下。没有快照时沿用原切换。
- 高级设置增加默认关闭的“无线性能保护（实验性）”，下次连接生效。只在无线会话请求 Android Wi-Fi 性能锁，会话结束时释放；不修改网络、热点和配对策略。

详细行为见[等待页面](projection-waiting-zh.md)、[分屏衔接](split-resize-zh.md)和[无线性能保护](../wireless-performance-zh.md)。截图是本地生成的中文合成画面，不包含真实导航位置、歌曲或车内图像，PNG 不随功能分支提交。

自动化检查覆盖首帧版本、超时、无效快照、触摸恢复、分屏历史、性能锁生命周期和各语言设置文案。组合后的实车回归日志仍需补充：连续连接/断线/重连、全屏与不同分屏宽度切换、仪表持续显示，以及无线性能开关前后的同条件诊断报告。Wi-Fi 锁能否生效由车机固件决定，本地测试不能证明延迟改善；本地新帧也不等于 iPhone 已确认区域切换。
