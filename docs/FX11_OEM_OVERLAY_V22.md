# FX11 原厂仪表叠加（v22，实验性）

新增第四个样式 `OEM_OVERLAY`（序号 4），已有 OFF/Midnight/Panorama/Replica 的持久化序号和页面选择不变。

## 使用流程

选择博越 L 后，在“本地仪表样式”选择“原厂仪表叠加（实验性）”。重新连接普通 CarPlay，使手机使用新的地图尺寸。随后点击“开启／关闭原厂仪表叠加”或短按 MODE。

中央区域显示 CarPlay 地图、导航文字和音乐。内容支持全部信息、导航、音乐三页，初次默认全部信息，使用原有 MENU 翻页模式及设置中的内容选择切换。地图使用现有 MapMirrors 普通 CarPlay 副屏流；不需要启用 Ultra。

原厂负责车速、转速、灯光、车况和其他区域。新图层不绘制全屏背景和自定义表盘；没有地图新帧时隐藏 TextureView，音乐或导航无数据时不绘制占位卡片。CarPlay 数据清理由现有会话结束流程负责。地图、导航、音乐的区域均限制在 1920×532 中间 x=600..1320；需要实车确认是否符合当前原厂主题。

## 模式控制

旧三套仪表继续使用 ECARX `SETTING_FUNC_THREE_SCREEN_ANIMATION`（540148992）0/1。

叠加样式独立使用 AutoService FX11 映射所指向的 VHAL 通道：

- 反馈：561023759 `panotifdimshowhide`，允许单整数或已知 PA_IntBase 有效载荷；不把空值当成 0。
- 命令：557876790 `cbnotifdimshowhide`，只发送全局区域单整数 0 或 3。
- 只有属性目录明确包含可读反馈和可写命令后才允许请求。
- 配置、服务启动、显示绘制本身不写车辆模式；必须明确点击开关或按 MODE。
- 每次请求最多写一次，随后回读；超时、拒绝、未知状态不自动重试。
- 当前反馈为 1 或其他未知值时不从新通道强行接管，应先恢复原厂模式。
- 在发送 3 前持久化“需要恢复”标记。退出或切到旧样式时先回读确认 0，成功后才移除旧窗口、切换控制器。恢复失败保留原选择与窗口。
- 从未尝试开启叠加且没有待执行请求时，可直接退出该样式；不支持通道的车辆不会被锁在这个设置中。
- 不调用 AutoService AIDL、不注入原厂地图、不启用 QNX 接收程序，也没有照搬每秒写模式的保活策略。

此协议依据 APK 静态证据实现。命令返回成功和状态回读 3 都不等同于物理仪表的透明合成已经验证。

## 诊断

导出的已有仪表诊断包含样式、页码、窗口状态、模式写入及回读结果；新增 `overlayRestoreRequired`。新通道日志使用 `OEM-overlay VHAL` 前缀。

重点确认：原厂表盘是否仍在、中央内容是否遮挡原厂提示、没有导航时文字卡片是否消失、断开 CarPlay 后旧画面是否清除、按 MODE 是否能恢复，以及切回原三套仪表是否正常。
