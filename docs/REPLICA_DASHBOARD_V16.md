# 复刻仪表 v16：统一的音乐 / 导航 / 胎压界面

设计基准为 `outputs/replica-unified-icons-preview-v8` 的效果图，实际实现为 Android Canvas/TextureView，固定设计坐标 1920×532。不把效果图、模拟地图或模拟读数打入生产仪表。

## 布局

- 三种页面共用同一顶部绘制函数和同一对圆盘。圆盘中心为 `(266,266)`、`(1654,266)`，半径 254；所有页面的转速文字位置固定。
- 地图与音乐背景的横向范围为两个圆盘中心之间。圆盘完整不透明，地图不会穿透速度、档位或刻度。
- 导航视频请求改为 1388×532，安全区 top=160、bottom=68、left/right=282；允许图像延伸到安全区外，控制/导航内容留在中间。旧宽高比视频按比例铺满，不能拉伸。
- 导航文字仅在收到实际导航信息时绘制；没有导航信息时整个文字面板消失。
- 音乐背景对真实封面做 24×24 缩略与模糊、明暗渐变；只在封面或 bitmap generation 改变时重建，切换封面与断连会更新/清除。歌曲进度条不显示时间数字。
- 左圆盘底部改为水温图标和摄氏温度，不显示油量百分比或续航。底部统一为时间、外温、剩余续航（燃油图标 + km）；不显示总里程。

## 统一的顶部状态栏

左右转向灯分别位于整排两端。AUTO 与近光合并：灯体颜色依据近光实际反馈，只有 AUTO 选择器明确返回 true 时才在图标内加入 A。远光仍保留独立蓝色指示，避免把远光状态丢掉。

位置灯、前/后雾灯、陡坡缓降、车道居中、巡航图标、模式名称、带 km/h 单位的设定速度、车距图标/三条距离条都固定在同一坐标。距离条自上而下从长到短。模式名称与速度按实际文本宽度相邻排列。

辅助驾驶不再显示“激活 / 未激活 / 待命”等状态文字：确认激活为绿色，未知或未激活为灰色，故障为黄色并显示叹号。GPilot 的绿色方向盘仍要求纵向激活及已确认横向控制反馈；不能由模式选择或车道线颜色推断。

AutoHold 和驻车制动图标在档位附近，只有确认 true 才显示，分别为绿色 A、红色 P；false、缺失或过期均隐藏。陡坡缓降也是确认 true 才显示。

## 数据范围与限制

- 水温新增 `ENGINE_COOLANT_C`，读取 Android 标准 `ENGINE_COOLANT_TEMP`（0x11600301），单位 °C。仅在固件宣告全局可读时采集；缺失显示 `—°C`。不是发动机油温，也不是外温的替代值。
- 手刹新增标准 `PARKING_BRAKE_ON`（0x11200402）。HIDL BOOLEAN 使用单个 int32，严格只接受 0/1；未宣告、不可读、状态无效或过期时隐藏。
- 上述字段定义依据 [Android VehiclePropertyIds](https://developer.android.com/reference/android/car/VehiclePropertyIds)。实车是否提供正确反馈仍待验证。
- AutoHold 与陡坡缓降的 UI/状态模型已实现，但目前没有已验证的 FX11 反馈属性及枚举，不添加猜测映射，实车默认隐藏。
- ACC 原始目标速度单位、车道居中枚举保持未确认；不把 RAW 数值直接标成 km/h。
- 已验证的 OEM 油量、续航、外温、胎压和转向灯映射保持原样；MODE 控制、候选 RESET 监听、普通 CarPlay、Midnight 和 Panorama 的行为不变。

## 验证

Robolectric 原生绘制检查三种页面的整条顶部像素一致、两个圆盘内部像素一致；覆盖 AUTO 合并、灯光状态、公里数/水温缺失、音乐断连与封面复用、驻车状态隐藏、导航面板隐藏、地图宽高比以及 1920/960 宽度和大字体中/阿文截图。

`common/build/reports/native-dashboard/` 中截图是应用代码渲染的示例数据，不是车机实测截图。测试地图纹理只存在于测试代码。
