当前基线：DiPlay main `c30d3f0df18dd132739d864a9e054c73b3d57d8c`（2026-10-14 合并）。
最初适配基线为 `8352021c0bc2612fff2e51c9a760abf95a5c5c54`；博越 L 定制改动继续保留。
DIM 桥接代码移植自用户本地 carlink `c839f925d28eb5ce8ba59530b73bfee958dd7595`。

第一阶段接入原厂 DIM 信息与普通 CarPlay 地图副屏。2026-10-14 新增 Ultra 实验协议接入，范围与未完成项见 [BOYUE_ULTRA.md](BOYUE_ULTRA.md)。

## 设置

1. 设置 → 车辆 → 车型适配 → 吉利博越 L（FX11）。车型切换后重新连接 CarPlay。
2. 同卡片开启方向盘按键，并配置播放、上一曲、下一曲短按和语音键长按。
   可选不处理、播放/暂停、上一曲、下一曲、Siri。设置立即生效。
   使用车载蓝牙音频时，媒体键由原车 AVRCP 处理，避免同时发送两次。
   当前只订阅已知四个键码；不包含任意键录入。语音键短按仍由原车处理。
   不自动停用 HiCar，也不宣称拦截其他系统按键消费者。
3. 设置 → 高级 → 博越 L 仪表显示（实验性）→ 原厂仪表音乐与导航信息。
   此项默认关闭，开启后随 CarPlay 媒体控制器接入 DIM；关闭或控制器销毁时清理输出。
4. 如需封面，Android 11+ 可通过“封面公共目录权限 / 重发”授权本应用的所有文件访问。
   然后再次点击重发。只在有封面且已授权时写入 Documents/DiPlay/dim-artwork/current。
   歌名、艺人、专辑不依赖此权限。保留 Bitmap getter，但原厂 URI 读取能否显示封面仍需实车确认。
5. 开启“仪表显示 CarPlay 地图”并重新连接 CarPlay。此项默认关闭。

6. 可选开启“FX11 车况发送到 iPhone（实验性）”并重连；车速、挡位、车外温度经普通 iAP2 发送，详见 [FX11_CARPLAY_DATA.md](FX11_CARPLAY_DATA.md)。

## 地图如何到达仪表

iPhone 的副屏视频（type 111）→ DiPlay 既有副屏解码器 → Android Presentation Surface → Display 4。

博越 L 分支只接受有效、开启、非私有、具有 PRESENTATION 标志的 Display 4，实际分辨率必须为 1920×532。
会话声明精确使用 1920×532、30 fps，不套用 BYD 的缩放及高度取整规则。
找不到目标屏时不声明该车型副屏，也不降级到 BYD 显示或默认主屏。
博越 L 不使用 BYD 的 ADB 仪表路由。旧版全屏 CarPlay 地图在离开投屏 Activity 时关闭 Presentation；新增[本地仪表](NATIVE_FX11_DASHBOARD.md)使用独立前台服务，离开 CarPlay 后仍可显示车况。

Android 创建窗口/收到视频流不等于物理仪表已经切换到该画面。
依据此前 FX11 研究，实屏可见性可能需要手动开启原车三屏动画；本实现不写原车模式开关。
停车验证，并在结束后手动关闭三屏动画恢复原厂仪表。

## DIM 信息链路

- 歌曲：iAP2 Now Playing / artwork → 原有媒体缓存 → DIM playlist/playback/progress。
- 导航：iAP2 RouteGuidance → 独立生命周期解析状态 → ECARX TBT 与导航状态。
- 位置更新不重发整张封面；只更新进度，播放/暂停变化时更新播放状态。
- 导航结束、过期或会话断开后清除旧指令；不会沿用 BYD 的断线保留策略。
- 不把导航距离当车速。未知车速为 -1；未知目的地坐标不发送给旧版导航摘要接口。
- DIM setter 没有仪表呈现确认；诊断中的“已调用”不表示实屏已显示。

## 验收顺序

1. 普通 CarPlay 主屏连接与音频先正常。
2. 按四个方向盘按钮，核对自定义动作、禁用、蓝牙音频防重复行为。
3. 播放、暂停、切歌，观察原厂仪表的歌名、艺人、进度和可选封面。
4. 启动真实路线，核对箭头、下一道路、距离；结束导航和断开手机后应清除。
5. 查看“仪表连接状态”，核对 Display 4 参数；打开地图开关并重新连接。
6. 观察真实仪表地图，验证前后台、断连、关开开关及原厂仪表恢复。
7. Ultra 协议已按后续要求提前接入；真实原生仪表闭环仍按 BOYUE_ULTRA.md 单独验收。
