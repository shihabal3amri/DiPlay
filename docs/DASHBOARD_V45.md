# v45：可选麦克风输入

针对 CarPlay 通话对方听不到声音，参考本地 Carlink 的 AudioRoutePreferences 和 MicrophoneCaptureManager：

- 设置 → 音频 → 语音输入通道（麦克风）：自动、7 通话处理、1 普通麦克风、6 语音识别、0 系统默认、5 摄像录音、9 未经处理。
- 麦克风输入设备：自动或 Android 当前枚举到的输入设备。按类型、地址和名称持久化，不保存重启后会变化的设备 ID。
- 通话及 Siri 共用上述设置。每个新麦克风会话读取一次；修改设置不会打断当前通话，不需要重连整个 CarPlay。
- 默认自动保留原 Geely/Siri/电话来源选择及自动模式下的识别源失败回退。明确选择的来源不悄悄回退；设备不存在或拒绝路由时释放录音器并恢复通话音频模式，诊断记录 INPUT_ROUTING。
- 输入源编号属于 AudioRecord，与音乐、导航输出通道编号含义不同。可先试 7，再试 1、6；每次结束通话后重拨验证。设备支持哪些来源以及实际声音仍需实车确认。
- 日志记录请求/实际来源、设备类型，以及既有每五秒采样峰值、读取字节数与上行发包计数；不新增录音文件，不记录设备地址。
- 车机已有 RECORD_AUDIO 权限，当前会话日志未找到可用的麦克风诊断，暂不能断言故障根因。
- 保留三套仪表、普通 CarPlay、v44 重绘/缓冲/卡顿诊断，以及已验证的认证资源。

仅增加麦克风输入配置，不改变手机协商的上行音频编码、采样率或声道数。
