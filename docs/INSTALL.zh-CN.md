# 安装与连接

[简体中文首页](../README.zh-CN.md) · [英文安装指南](INSTALL.md) · [繁體中文安裝指南](INSTALL.zh-TW.md)

## 安装前准备

1. 停车后，从[官方 0.2.22 版本](https://github.com/shihabal3amri/DiPlay/releases/tag/v0.2.22)下载 APK。此版本需要 Android 7.0 以上（API 24+）；Android 7.0–8.1 的有线 CarPlay 已在一台实车上确认，无线连接尚待实车验证。
2. 按车机支持的方式把 APK 安装在 **Android 车机**上，不要安装在 iPhone。能否安装 APK 由车机固件决定。
3. 更新已有安装时，使用相同的应用包名／变体和匹配的签名，才能保留设置与配对记录；签名不同无法覆盖安装，卸载会清除应用私有数据。不要凭文件名判断更新兼容性。
4. 打开 DiPlay，按所用功能授予蓝牙／附近设备、Wi-Fi／位置（较旧 Android 的无线连接需要）和麦克风（Siri／通话）权限；通知权限用于连接控制。
5. 连接前关闭其他手机投影应用。首次启动的设置向导可以跳过，也能从设置重新打开；其中的车型标签不代表完整兼容性保证。

切换语言：**设置 → 语言 → 应用语言 → 简体中文 → 应用**。语言页也提供**跟随系统**。

## 无线：车机热点

车机热点是默认连接方式。

1. 在车机系统设置中打开内置热点；如可选频段，优先 5 GHz。
2. 在 DiPlay 打开 **设置 → 连接 → 连接设置**，选择 **车机热点**。
3. 准确填写热点名称和密码并保存。
4. 保持 iPhone 的蓝牙和 Wi-Fi 开启并与车机配对；必要时用 **选择 iPhone** 指定要使用的配对设备。
5. 点按 **连接手机**，在 iPhone 上接受 CarPlay 提示。

兼容固件可通过蓝牙握手提供热点凭据，实现自动加入；核心 CarPlay 不需要 ADB。如果 iPhone 没有自动加入，先确认该热点的“自动加入”，再测试手动加入能否开始 CarPlay，并把结果记入诊断报告；不要直接假设密码或 CarPlay 传输本身失效。单独确认的[实验性加入修复](WIRELESS_HOTSPOT_JOIN.md)和完整的[连接设置指南](CONNECTION_SETUP.md)目前为英文。

**自动启动车机热点**是单独的选装设置，默认关闭。在受支持的比亚迪固件上，显式开启它会通过已授权的本机 ADB 为 DiPlay 自己的包验证权限；它保留车机已存的热点名称／密码，“开机启动”和“打开 DiPlay 时连接”是分开的设置。这不代表所有 DiLink 版本都受支持。

## 无线：Wi-Fi Direct

在 **连接设置** 选择 **Wi-Fi Direct**，保持车机 Wi-Fi、蓝牙及 iPhone Wi-Fi 开启，再连接。需要车机固件实现相应的 API。

- Android 7.0–9 依赖固件相关的旧版建组路径，使用系统生成的群组凭据，无法读回实际协商频率；Android 10 以上保留群组频率验证。车机能连上 5 GHz 网络，不代表能建立 5 GHz Wi-Fi Direct 群组。
- **首选信道**为“自动”时保持自动选择：靠近 5 GHz 站点时，先尝试符合条件的已存／对齐信道和明确的 2.4 GHz，再回退到其他 5 GHz／系统默认；它不保证频段。**自动 · 5 GHz** 和 **自动 · 2.4 GHz** 把自动尝试限制在所选频段（受硬件支持），旧版 Android 仍无法验证协商频率。
- 可保存受支持的 2.4/5 GHz 信道供下次连接使用；正在进行的会话不会因单纯选择而中断，直到重新连接。若射频拒绝该信道或建到了别的信道，改回“自动”或其他信道再重连。地区和射频支持仍然适用，选择信道不代表卡顿已修复。
- 若车机反复扫描 Wi-Fi 导致声音或画面卡顿，先测试车机热点。旧版的频道设置、群组清理及持久配置限制见 [Android 9 Wi-Fi Direct](ANDROID9_WIFI_DIRECT.md)。

## 无线：现有 Wi-Fi／同一局域网

1. 在车机和 iPhone 的系统设置中，把两者连到同一台外部路由器或随身 Wi-Fi。
2. 关闭路由器的客户端隔离；保持蓝牙开启。
3. 在 DiPlay 的 **连接设置** 选择 **现有 Wi-Fi / 同一局域网**，保存该网络的信息，再连接。

DiPlay 不替你加入外部网络、不修改默认路由，也不在此模式建立热点。设置条件与验证记录见[同一局域网指南](EXISTING_WIFI.md)。“本地热点”选项已移除，原有选择会迁移到内置热点；USB 仍可用。

## 有线：USB

1. 用支持数据传输的 USB 线，把 iPhone 连到车机的 **USB 数据接口**；仅充电的接口或线材无法使用。
2. 点按 **通过 USB 连接**。
3. 按提示允许 USB 访问，在 iPhone 上确认信任／CarPlay，并在出现时允许本机 VPN 权限。

本机 VPN 承载的是 USB 网络链路，不是上网用的 VPN 服务。若有线 CarPlay 每隔几秒断开又自动重连，先试 **设置 → 连接 → USB 连接 → iPhone 充电 → Reduced（降低）**，再试 **Low（低）**；iPhone 的充电速度也会随之变慢。

## 连接之后

先用默认图标大小、30 fps，并在 **设置 → 高级 → 视频与音频** 保持 **高效视频（HEVC）** 关闭；较慢的车机可尝试 80% 或 60% 分辨率。部分 iPhone／车机组合仍可能忽略图标与文字缩放。

部分设置即时生效，部分在下次连接生效。会话进行中，显示调整使用 **应用并重新连接**；只选择新值不会立即生效，取消则保留旧设置。未连接时保存的设置在下次连接生效。请以各设置项的说明为准：有的即时生效，有的会显示 **立即重连** 并在下次连接生效。

连不上时，参考[兼容性与疑难排查指南（英文）](COMPATIBILITY.md)；涉及 HUD／仪表板的车型整合，另见[比亚迪导航指南](BYD_NAVIGATION.md)。

遇到未解决的问题，请在 **0.2.22** 上复现后，用 **设置 → 诊断 → 保存诊断报告** 导出新报告（Android 10+ 通常保存到 Downloads/DiPlay），把 `.txt` 作为文件附到对应的 [GitHub issue](https://github.com/shihabal3amri/DiPlay/issues)，注明车型／车机、DiLink/Android/完整固件版本、iPhone/iOS、连接方式（USB／车机热点／Wi-Fi Direct／同一局域网）、相关设置、复现步骤与故障时间。报告只在你选择分享时发送，请勿公开热点密码。
