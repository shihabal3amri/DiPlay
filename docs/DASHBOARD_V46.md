# v46：白天黑底与 AutoHold 实际保持

白天经典仪表继续使用浅色圆盘与固定刻度渐变；圆盘外、无地图占位区及中央音乐页改为黑底。胎压文字改为浅色，右侧音乐圆盘的封面与配色保持原逻辑。真实 CarPlay 地图像素不改色。

AutoHold 来源是 QNX FDBus `TelltaleModule` 的 event 1、lampId 32，**不是 VHAL 属性 32**。2026-10-24 会话“分析博越L仪表与AutoHold信息”实车验证：绿灯亮 32=1，功能仍开启但停止保持 32=0；普通 APK UID 可直接订阅，不依赖 AutoService、root 或电脑转发。

移入该会话验证的只读 native reader（原始来源和 Apache 2.0 许可位于 common/fx11-telltale-native），从 Android 管理的 nativeLibraryDir 启动。启动时用车机 lssvc 发现固定 QNX 对端 192.168.118.2 的动态端口，不写车辆属性、不执行业务 invoke。

解析按 213 字节中的计数和编号/状态对查找，不固定偏移。首次缺失 32 保持未知；增量消息未含 32 保留已确认值；完整快照缺失、非法枚举、重复编号、异常填充、断线和 25 秒无活跃数据清除状态。只读 GET_EVENT 检查连接存活，失败重连。退出最后一个仪表观察者时停止进程和看门狗。

绿色仅表示实际保持，未保持/未知显示原有灰色 AutoHold 图标，诊断区区分 false 与 unknown。保留手刹逻辑、三套仪表、普通 CarPlay、v45 麦克风输入选择及认证资源。

本包的车辆绿灯变化仍待安装后复核；来源协议和普通 APK 订阅能力已由同车另一会话实测。
