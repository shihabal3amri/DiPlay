## 原厂 DIM 信息联动

- 选择 Midnight / Panorama / Classic：关闭原厂音乐与导航信息。
- 选择 OFF（原厂）或 OEM_OVERLAY（保留原厂圆盘）：打开原厂信息。
- 通过方向盘切换三屏：仅在控制器成功回读后联动；原厂 mode 0 打开，完整自定义仪表关闭。
- 切换失败/超时不伪造成功、不改当前 DIM 开关；关闭仪表仍先恢复原厂再保存 OFF。
- 继续保留手动 DIM 开关，下一次成功切换会按上述规则联动。界面实时刷新，不因此要求重连。

## 车辆 → 方向盘按键

博越 L 的按键配置从“车型适配”移到“方向盘按键”卡片，每个已支持按键分别配置短按与长按。
包括已校准 MODE、MENU、播放、上一曲、下一曲、语音键，以及此前已学习的其他翻页键。
动作：不处理、播放/暂停、上一曲、下一曲、Siri、切换原厂/自定义仪表、切换音乐/导航/胎压。
默认 MODE 短按仍切换仪表；语音键的旧设置仍是长按，其他新增长按默认不处理。
可例如设置“MODE 短按 → 切换原厂/自定义仪表；MODE 长按 → 切换音乐/导航/胎压”。
需要先选定一个自定义仪表样式；关闭整个仪表服务（OFF）时不响应自定义仪表动作。

使用 OneOS 的 onShortClick / onLongPressTriggered，以及 holdingStarted/Stopped 去重。
不把未知 raw event 数值或计时猜测当成按住时长。持续按住只执行一次已配置长按；松手后的短按回调被抑制。
短按/长按设置立即生效并重绑监听，旧 Binder 回调受 epoch 隔离。
车机必须实际提供长按事件；本机无法证明某个实体按键是否提供该事件。
仍只监听，不拦截原厂按键，也不改变辅助驾驶或车距滚轮。
蓝牙 AVRCP 的媒体去重规则保留；自定义仪表动作可离线使用，不受蓝牙音频开关限制。
MENU 原厂状态翻页继续作为未自定义媒体短按时的默认行为；显式按键设置优先。
配置新的翻页动作后，未确认的 DTE 候选自动翻页被抑制，避免多个通道翻两页。
Midnight/Classic 循环音乐→导航→胎压；Panorama 保持地图并切换音乐/胎压卡片，延续原样式行为。
